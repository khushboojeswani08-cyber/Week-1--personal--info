# Student Grade Calculator

## Project Overview

This is a Python program that calculates grades for multiple students based on their marks in three subjects. It also provides personalized comments and class statistics.

## What I Learned

- Conditional logic using if/elif/else
- Comparison operators
- Lists and list operations
- For loops and while loops
- Error handling using try-except
- Functions for reusable code
- Calculating statistics using Python

## Features

- Processes multiple students
- Accepts marks for Math, Science, and English
- Validates marks between 0 and 100
- Calculates student averages
- Assigns grades from A to F
- Provides personalized comments
- Calculates class average
- Shows highest and lowest averages
- Displays results in a formatted table
- Handles invalid user input

## Grading System

| Average | Grade | Comment |
|---|---|---|
| 90-100 | A | Excellent! Keep up the great work! |
| 80-89 | B | Very Good! You're doing well. |
| 70-79 | C | Good. Room for improvement. |
| 60-69 | D | Needs Improvement. Please study more. |
| 0-59 | F | Please seek help and work harder. |

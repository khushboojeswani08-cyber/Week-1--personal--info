Personal Information Manager

## Project Description
This is my first Python project. It is a simple program that stores and displays personal information.

## What I Learned
- Variables
- Input and Output
- String Formatting using f-strings
- Basic Input Validation
- Basic Python Programming

## Features
- Stores name, age, city, and hobby
- Takes favorite food and color as input
- Calculates age in months
- Displays information in a formatted way
- Validates empty input

## How to Run
1. Install Python.
2. Open the `personal_info.py` file.
3. Run the program.
4. Enter your favorite food and favorite color.

## Testing
The program was tested with different food and color inputs.

Example:
- Favorite Food: Dal baati
- Favorite Color: Black

## Challenges & Solutions
Challenge: The user may enter empty input.

Solution: Added input validation using a while loop.
